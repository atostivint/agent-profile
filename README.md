# agent-profile

An agent-facing profile for Alexandre Tostivint, published as plain Markdown on
GitHub Pages: <https://atostivint.github.io/agent-profile/>

The idea, borrowed from [lauren.md](https://lauren.md): the first reader of a
profile is increasingly a model, and a model fills gaps with guesses. A short
Markdown file, written *for* the agent, with explicit rules and explicit
non-facts, guesses less than a PDF does.

## What is here

| File | Role |
| ---- | ---- |
| `index.md` | **Single source of truth.** The agent-facing profile. Edit this one. |
| `index.html` | Generated human page (no JS, no CDN). Never edited by hand. |
| `llms.txt`, `AGENTS.md` | Generated byte-identical copies of `index.md`, for both conventions. |
| `scripts/build.py` | Stamps *last updated*, re-renders the page, regenerates the copies. |
| `scripts/verify_facts.py` | Drift gate: every claim must still exist in the CV repo. |
| `scripts/check_links.py` | Dead-link check on every URL in the profile. |
| `worker/content-negotiation.js` | Optional: Markdown at `/` for clients that ask for it (custom domain only). |

## Why the profile cannot silently drift

The CV (private repo `atostivint/curriculum-vitae`) is the authority. A profile
that repeats CV facts becomes a lie the day a certificate expires.

`verify_facts.py` parses the LaTeX sources and fails when:

- a certification in the CV is missing from the profile, renamed, or has a
  different date range or verification URL;
- the profile advertises a certification the CV no longer lists (the failure
  that actually ships);
- a counted claim (`10+ years in IT`, `8+ years in cloud`, `300+ customers`) is
  no longer supported by the CV wording;
- an employer, school or year span disappeared;
- a phone number or a salary/rate appears in the public file.

```bash
python3 scripts/verify_facts.py../curriculum-vitae
# checked 20 claim groups ...
# OK: profile consistent with the CV sources
```

## Build

```bash
python3 scripts/build.py            # stamps today's date from git, regenerates everything
python3 scripts/build.py --date 2026-11-02
```

## Publish (not automatic)

Production is GitHub Pages on `atostivint/agent-profile`, `main` branch, root
directory, with `.nojekyll` so `index.md` is served raw as
`text/markdown` (verified: GitHub Pages already does this for `.md` files).

Publishing steps that need a human decision, in order:

1. create the public repo and push;
2. enable Pages (branch `main`, root);
3. *optional* custom domain, e.g. `profile.alexandre.tostivint.bzh` — CNAME file
   at the root + Cloudflare CNAME → `atostivint.github.io`, DNS-only at first so
   the certificate can be issued;
4. *optional* Cloudflare Worker route for Markdown-at-root.

## Rules this profile carries

The file states, for any agent reading it: do not invent, quote numbers with
their timeframe, never state a rate or start date, keep my work distinct from my
team's, AWS is my primary cloud not Azure, and never contact anyone on my
behalf.
